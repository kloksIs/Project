## Описание проекта
Проект представляет собой клиент-серверное веб-приложение (онлайн-форум/ленту сообщений) с возможностью авторизации, ветвления обсуждений и сквозного поиска. В качестве уникальной фичи в тематику форума интегрированы дифференциальные уравнения (диффуры) — для тестирования и наполнения базы данных используются математические задачи и обсуждения алгоритмов их решения.

### Основной функционал
* **Авторизация и безопасность:** Регистрация новых пользователей и вход в систему по логину и защищенному паролю.
* **Интерактивная лента:** Возможность публикации главных постов (сообщений) на стене форума.
* **Система комментариев:** Поддержка древовидных обсуждений (создание веток ответов под конкретным сообщением, как на YouTube).
* **Умный поиск:** Быстрый поиск нужных постов и обсуждений по ключевым словам или автору сообщения.

### Архитектура системы
* **Клиент (Client):** Интерфейс взаимодействия с пользователем (отправка запросов на сервер, отображение ленты и комментариев).
* **Сервер (Server):** Обработка бизнес-логики приложения, маршрутизация запросов (регистрация, вход, публикация, поиск).
* **База данных (Database):** Надежное хранение учетных записей пользователей и всей истории сообщений/комментариев.
